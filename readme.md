## 🌿 About Guthli Foundation

**Guthli Foundation** is a community-driven social-impact initiative committed to nurturing potential, empowering individuals, and building a more sustainable and inclusive future.

We believe meaningful change begins with small actions, informed decisions, and people who are willing to make a difference.

This repository contains the source code for the Guthli Foundation website, designed to communicate our mission, showcase our initiatives, connect with communities, and create opportunities for people to participate in positive change.

## ✨ Website Highlights

The website serves as a digital home for Guthli Foundation, bringing its mission, people, and initiatives together.

| Feature | Description |
|---|---|
| 🌱 Mission & Identity | Communicates the foundation's purpose, values, and vision |
| 🎨 Interactive Design | Visual storytelling, engaging layouts, and thoughtful animations |
| ☀️ Animated Illustrations | Nature-inspired visuals, including the sun-and-plant illustration in the About section |
| 📱 Responsive Layout | Designed to provide a usable experience across desktop and mobile screen sizes |
| 📢 Initiative Showcase | A place to communicate programs, events, campaigns, and activities |

## 🎨 Design Philosophy

The visual identity is inspired by nature, growth, and the power of small beginnings.

- **Green** represents nature, growth, sustainability, and hope.
- **White and light backgrounds** support clarity and readability.
- **Organic illustrations** communicate growth and positive change.
- **Motion and transitions** add life without distracting from the content.
- **Responsive layouts** help make the experience accessible across devices.

The guiding idea is simple:

**A small seed can become something extraordinary—with the right environment, care, and time.**

## 🚀 Getting Started

Want to explore the code, improve the design, or contribute to the project? Follow these steps.

### Prerequisites

You will need:

- Git installed on your computer
- A modern web browser
- A code editor such as Visual Studio Code

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY` with the actual GitHub repository details.

### 2. Enter the project directory

```bash
cd YOUR-REPOSITORY
```

### 3. Open the project

Open the folder in Visual Studio Code:

```bash
code .
```

### 4. Run the website locally

If the project is a static HTML/CSS/JavaScript website, open `index.html` in your browser or use the **Live Server** extension in Visual Studio Code.

For the Live Server method:

1. Open the project folder.
2. Install the Live Server extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website should open in your browser.

## 🌻 Bringing the Website to Life

Animations are most effective when they reinforce the story behind the design.

The nature-inspired About section uses a sun-and-plant illustration to represent growth, care, and the gradual impact of small actions.

### ✨ Animation principles

- **Natural movement:** subtle floating and transition effects.
- **Visual hierarchy:** animations guide attention to meaningful elements.
- **Responsive behavior:** visual effects should remain usable on different screen sizes.
- **Accessibility:** respect reduced-motion preferences wherever possible.
- **Performance:** avoid unnecessary animation work and layout shifts.

## 🤝 Contributing

Guthli Foundation believes that meaningful progress comes from people working together.

If you would like to improve the website, suggest an idea, fix a bug, or contribute to the project's development, your participation is welcome.

### Contribution workflow

**1. Fork the repository**

Create your own copy of the project on GitHub.

**2. Create a feature branch**

```bash
git checkout -b feature/your-feature-name
```

**3. Make your changes**

Keep the code readable, preserve existing functionality, and test your changes locally.

**4. Commit your work**

```bash
git add .
git commit -m "Add: describe your improvement"
```

**5. Push your branch**

```bash
git push origin feature/your-feature-name
```

**6. Open a Pull Request**

Explain what you changed, why it matters, and how you tested it.

### Contribution guidelines

- Keep changes focused and easy to review.
- Use clear names for variables, functions, and files.
- Maintain responsive behavior.
- Consider accessibility and reduced-motion settings.
- Avoid introducing unnecessary dependencies.
- Never commit passwords, API keys, tokens, or other secrets.
- Be respectful and constructive when collaborating.
